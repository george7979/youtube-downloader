# YouTube Downloader 2.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild the app as a self-updating GUI + CLI over the official yt-dlp binary that saves an Obsidian-ready MP4 + note (with transcript from YouTube captions).

**Architecture:** Package `ytdownloader/` with a tkinter-free `core/` (paths, settings, naming, subtitles, note, tools, engine, service), a thin CustomTkinter `gui/` and an argparse `cli`. yt-dlp, ffmpeg and Deno are external binaries in the user data dir, managed by `core/tools.py`; yt-dlp runs as a subprocess with JSON progress lines.

**Tech Stack:** Python 3.12 (uv-managed, has Tk 9), customtkinter ≥ 6.0, Pillow, platformdirs ≥ 4, pytest; PyInstaller + NSIS + dpkg for packaging.

**Spec:** `docs/superpowers/specs/2026-10-18-v2-design.md` (Polish). Read §5–§8 before any task.

## Global Constraints

- Python **3.12**. Dev env: `uv sync --managed-python --python 3.12`; tests: `uv run pytest -q` (no network, ever).
- Runtime deps only: `customtkinter>=6.0`, `pillow>=10`, `platformdirs>=4`. **No `yt-dlp` Python package** anywhere (pyproject, spec, CI).
- `ytdownloader/core/**` must never import `tkinter` or `customtkinter`.
- No hardcoded `/tmp`, `~/Downloads`, `C:\…` — every location comes from `ytdownloader/core/paths.py`.
- UI copy and CLI output: **English only**.
- Subprocesses: `stdin=subprocess.DEVNULL`, `encoding="utf-8", errors="replace"`; on Windows `creationflags=subprocess.CREATE_NO_WINDOW`; yt-dlp always gets `--ignore-config`.
- An existing note (`.md`) is **never** overwritten (spec §6.7).
- Default quality **1080**; MP4 = H.264+AAC when available via `-S res:<q>,vcodec:h264,acodec:m4a` (verified 2026-10-18: lecture → `136+140 avc1 720`, 4K request → `vp9 2160`).
- Tool sources (verified 2026-10-18):
  - yt-dlp: `https://github.com/yt-dlp/yt-dlp/releases/latest/download/{yt-dlp.exe|yt-dlp_linux}`, sums `…/SHA2-256SUMS`
  - ffmpeg Windows: `https://github.com/yt-dlp/FFmpeg-Builds/releases/download/latest/ffmpeg-master-latest-win64-gpl-shared.zip` (84 MB, copy whole `*/bin/` dir); Linux: system `ffmpeg`+`ffprobe` on PATH if present, else `ffmpeg-master-latest-linux64-gpl.tar.xz` (149 MB, members `*/bin/ffmpeg`, `*/bin/ffprobe`); sums `…/latest/checksums.sha256`
  - Deno: `https://github.com/denoland/deno/releases/latest/download/deno-x86_64-{pc-windows-msvc|unknown-linux-gnu}.zip` + `<same>.sha256sum`; minimum version **2.3.0**
  - All sums files are lines `<sha256-hex>  <asset-name>`.
- Known tool pitfalls (verified): `zipfile.extractall` drops the exec bit → `chmod 0o755` after extract; `--print` makes yt-dlp quiet → always pass `--progress`; yt-dlp's own filename sanitizing turns `?` into `？` → we always pass our own `-o` built from `naming.safe_filename`.
- Subagent working rules: only the project directory; no `cd` (use absolute paths, `git -C`), no `rm -r`; scratch files in `.superpowers/sdd/tmp/` (git-ignored).
- Commit after each task with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>` trailer. Never push.

## Review Focus

1. Video titles with Windows-illegal characters, emoji, trailing dots/spaces, reserved names (`CON`, `nul.txt`), `%` (yt-dlp template syntax) or > 150 chars must yield a valid filename on both OSes — pinned in Task 4 and Task 8 (`%` → `%%` in `-o`, verified: `-o "100%% Pure.%(ext)s"` → `100% Pure.mp4`).
2. URL variants (`youtu.be/ID?si=…`, `watch?v=ID&list=…&t=42s`, `/shorts/ID`, `m.youtube.com`, `/live/ID`) must resolve to the one video, never a playlist — pinned in Task 3 + `--no-playlist` in Task 8.
3. Cancel while ffmpeg is merging must kill the whole process tree and leave no `.part`, `.ytdl`, `.fNNN.*`, `.vtt` files — pinned in Task 8 (fake child process) and Task 10 (cleanup).
4. Output folder removed or unwritable between Check and Download must give the `write_failed` friendly error, not a traceback — pinned in Task 10.
5. Interrupted tool download, checksum mismatch or no network on first run must leave no half-installed tool and allow a retry — pinned in Task 7.

- Consumes: `models.Chapter`
- Produces:
```python
@dataclass(frozen=True)
class Cue:
    start: float; end: float; text: str
@dataclass(frozen=True)
class Paragraph:
    start: float; text: str
def parse_vtt(text: str) -> list[Cue]               # strips header, cue settings, inline tags, HTML entities (&amp; &gt; &lt; &nbsp;)
def clean_auto(cues: list[Cue]) -> list[Cue]        # removes rolling repeats
def to_paragraphs(cues: list[Cue], chapters: list[Chapter], target: float = 45.0, hard: float = 90.0) -> list[Paragraph]
def to_srt(cues: list[Cue]) -> str
```
- `clean_auto` algorithm: keep `last_line = ""`; for each cue, split text into lines, drop empty lines and lines equal to `last_line`; if anything remains, emit `Cue(start, end, " ".join(remaining))` and set `last_line` to the cue's last non-empty line. Cues shorter than 0.05 s that contribute nothing are dropped.
- `to_paragraphs`: start a new paragraph at each chapter start; otherwise when `cue.start - para.start >= target` and the paragraph text ends with `.`, `?`, `!` or `…`, or when `>= hard`. Text joined with single spaces.
